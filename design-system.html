Usage rules: Burgundy is the primary brand colour: used for key CTAs, headings on cream backgrounds, and decorative elements. Gold is strictly an accent: divider lines, eyebrow labels, price text, hover states, and gold-outline buttons. Never use gold as a body text colour on light backgrounds (contrast too low). Cream tones are section backgrounds only. Charcoal is the default body text. White (#FAF6F0) text on Burgundy/dark backgrounds.

Type rules: Headings always use Cormorant Garamond. Italic weight is reserved for brand taglines and emotional emphasis, never used for body text. All UI labels, navigation, buttons, and body copy use Inter. Avoid weights above 600 in Inter for body contexts.

Border radius: The brand uses no border-radius on most elements (sharp, architectural feel). The only exceptions are: circular avatar/icon containers (50%), floating pills/badges (9999px), and scrollbar thumbs (3px). Do not apply rounded corners to cards, buttons, or input fields.
